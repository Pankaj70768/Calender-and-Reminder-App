# Calendar Reminder App

A modern Python-based Calendar Reminder Application built using Python and Tkinter.

## Features

- Calendar Interface
- Reminder Scheduling
- Notifications
- Voice Input
- Search Reminder
- Delete Reminder
- Clear All
- Theme Toggle
- Categories
- Local File Storage

## Technologies Used

- Python
- Tkinter
- TkCalendar
- SpeechRecognition
